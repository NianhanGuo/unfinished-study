# V5 opening and audio

Only the opening presentation and audio are extended. Studio geometry, pursuit, drawing and endings are retained.

Resources/HorrorMusic.wav is the user-supplied audio, copied byte-for-byte. The user supplied the asset; no external license is asserted.
Resources/Heartbeat.wav is an original synthesized two-part pulse, generated by Tools/make_intro_assets.py. Its pitch is fixed; the playback interval follows nearest skeleton distance, smoothed over time.
Resources/HomeworkNote.png contains the original game premise and rules, rasterized with the locally available Bradley Hand font. The font itself is not redistributed.
StudyIntro.cs creates two-sided paper halves and cloned holding hands, animates the hinge, withdraws the folded sheet, then raises the existing drawing board.
StudySoundscape.cs adds separate music and heartbeat sources without changing the original pencil, wheels or room audio.

The revised posed hand meshes derive from immersive-web/webxr-input-profiles generic-hand under the MIT License (see GenericHand-LICENSE.md). Source: https://github.com/immersive-web/webxr-input-profiles/tree/main/packages/assets/profiles/generic-hand . Tools/pose_hands.py converts the skinned source into board-space grip poses; the wrist opening is hidden beneath fitted sweatshirt cuffs. The original anatomical topology replaces the earlier procedural finger forms.

V6: narrative and controls return to the original title page. The physical note contains only the three studies and the warning "They move when you're not paying attention." A separate Reading phase waits for the player to put the note away.
