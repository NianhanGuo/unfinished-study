# Unfinished Study — Drawing + Design prototype

使用 Unity **6000.0.34f1** 打开本项目，打开 `Assets/Study/Studio.unity`，点击 Play。
进入流程：**动态工作室封面 → 作业选择 → 简短准备页 → 游戏**。封面点击按钮或按 Enter；作业选择页按 **1 / Enter** 选择 Drawing，按 **2** 选择 Design，Escape 返回封面。两关均直接开放，无需通关解锁。

封面使用实时缓慢环绕镜头与独立的冷暖灯光；进入 Drawing 时恢复原来的玩家镜头与照明。作业卡片使用游戏内渲染的实景图片。Design 准备页先展示工作室空间，移动与操作提示在进入教室后短暂出现。

## 2026-10-06：注意力与追逐改进

- Drawing：观察缩至 0.9 秒，记忆保持 5 秒；三幅有效绘制时间为 26 / 28 / 30 秒。新增观察圆环、遮挡和完成提示，骨架头部或胸部受光都能暂停，近距离接触留出 0.22 秒救场判定。
- 后方骨架绕行基础速度 0.9，短暂保持绕行目标，沿可通行路线移动；恢复低音量的空间轮子声。
- Design：工作距离 1.45 米，需要面向材料并停止移动；转身、移动、松开 E 都可立即中断，保留当前进度。
- 裁切三次（总 9 秒），组装三块（总 12 秒），拍照需对准模型（4 秒）。每次裁切/放置后释放 E 再开始下一次。裁切声与拍照闪光/快门会引导老师检查来源，组装相对安静。
- 老师：10 米 / 120° 主视野，1.5 米近身感知；首次预警 1.8 秒，其后 1.2 秒。遮挡后只使用最后目击位置；搜索按固定朝向扫视，探头承诺攻击旧位置。
- 冲刺保留 4 秒容量；停止冲刺后延迟 0.8 秒恢复，恢复速率 0.8/秒；耗尽后恢复到 20% 才能再次冲刺，避免逐帧跑走闪烁。
- 连续面部网格替代脸部几何体堆叠；老师肢端交替固定、抬起换步，增加收颈动作。工作台加入操作手部、定位线、材料变化和取景框。
- 工作室增加木材/纸张材质、裁切痕迹、批注、边角料、梁与管线；降低桌面以强化钻桌视角，装饰不改变通路碰撞。

调参入口：`Assets/Study/Scripts/StudyTuning.cs`。这些是首轮试玩参数，自动检查不能证明紧张度或可玩性；优先观察逃脱后是否获得 2–4 秒有效制作时间。

## Design：The Critique（可玩原型）

讲评已经开始，老师要把还没做完模型的学生带到前排。完成 **裁切 → 组装 → 拍照 → 交到讲评台** 即可过关。

- WASD 移动、鼠标观察；按住 Shift 冲刺，体力会恢复。
- 按住 C 或左 Ctrl 蹲下，钻工作台底；桌子挡住站起动作。
- 靠近当前编号工作台，对准标记区域按住 E 制作；松开、转身或移动即可逃跑，已完成的进度保留。
- 老师是有秃顶、眼镜和西装特征的程序化蜘蛛替身。天花板巡视、发现预警、快速追逐、失去视线搜索、伸长脖子探桌底及抓空恢复均可运行。
- 高隔板阻断视线和天花板路线；钻桌后需要在头部探入时从另一侧离开，不能无限藏在桌下。
- 每次裁切的声音，以及拍照的快门和闪光会吸引附近老师检查来源。灯光用于照明，不会定住 Design 老师。
- Escape 暂停；失败可重试 Design，也可以返回菜单重新选择作业。

关卡运行时由 `DesignPrototype` 创建独立场景；无需外部素材或额外场景配置，原 Drawing 场景保持可用。当前美术和音效仍是程序化原型；工作已分成有定位、分段进度和材料反馈的短动作，尚非自由模型编辑器。

菜单验证：编辑器桥接命令 `menuqa` 检查封面运动、页面切换、灯光恢复与两关入口，截图存于 `MenuQA-output/`。

验证：`DesignQA` 在真实 Play Mode 中检查工作进度、提交胜利、桌底碰撞、视线遮挡、绕障路线、追逐与攻击、暂停、重试、返回菜单及 Drawing 启动。编辑器桥接命令 `designqa` 运行检查，结果与截图写入忽略提交的 `DesignQA-output/`。

# 未完成的习作 / Unfinished Study · V7

Unity 6000.0.34f1，Mac 第一人称恐怖绘画小游戏。

## 开始游戏

打开 `Mac-v7/Unfinished Study.app`，按 Return 或点击 FINISH THE HOMEWORK 进入任务纸条。读完后再次按 Return 或点击 PUT THE NOTE AWAY，玩家会折起纸条收好，再拿出画板。

1. WASD 移动，鼠标转头，头灯跟随视线。
2. 找到标有 01 的骨架，把画面中心对准躯干，持续观察约 1.2 秒。圆环填满后获得 5 秒绘画记忆。
3. 按住空格或鼠标左键低头画画。手会跟随笔画，纸上留下真实炭笔线条；右侧显示绘画阶段、百分比和剩余记忆。
4. 松开按键抬头。头灯照到骨架躯干时它会静止，低头后它会重新靠近。画画时仍可移动，但速度变慢。
5. 记忆耗尽时重新观察。画完当前对象后，寻找 02 和 03；已完成的骨架仍会追逐。
6. 完成两具骨架与一组石膏头像、梨和白布静物，最后一笔落下后顶灯亮起。片刻后展示三张完成的习作。

接触骨架会触发手伸向画板、破坏素描与切黑的失败结局。没有尖叫跳脸。
ESC 暂停／继续；结束后按 R 重来。建议戴耳机，从较低音量开始。

## Unity 工程

打开 `UnfinishedStudy`，场景为 `Assets/Study/Studio.unity`。采用内置渲染管线，不依赖 URP 或额外插件。

- `Assets/Study/Scripts`：玩家、绘画、骨架追逐、寻路及自动检查。
- `Assets/Study/ArtV2`：OBJ 模型、真实材质、录音与来源说明。
- `Assets/Study/ArtV4`：连续手部网格、光束贴图和说明。
- `Assets/Study/ArtV3`：三张炭笔画稿及完整生成 prompt（GENERATION.json）。
- `Assets/Study/Resources`：纸张、完成画作、逐笔路径 JSON、着色器和字体。
- `Assets/Study/Editor/StudioBuilder.cs`、`StudioUpgrade.cs`、`StudioRealism.cs`：场景生成器。
- `Tools`：可选的模型／画稿生成源代码。打开或运行游戏不需要 Python。

菜单 Study > Build Studio 会重建生成场景，覆盖该场景中的手工调整。手工修改前请另存场景。骨架敌人采用独立硬质部件与程序驱动姿势。V7 双手在 Blender 中利用关节骨架摆姿后烘焙为连续网格；游戏运行时不需要 Blender。

## 交作业说明

这是包含完整输赢循环的可玩风格原型。建模、玩法脚本、素描路径和场景搭建由 AI 辅助生成；外部纹理与声音来源列在 `素材来源.md`，请按课程规则披露 AI 使用。骨架仍是风格化的教学模型，不宜当作精确解剖参考。

`QA-results-v7.txt` 记录 Unity Play Mode 的检查结果；`PreviewsV7` 保存实际游戏画面，截图检查中使用自动控制和设定进度来覆盖不同状态，并非人工完整通关录像。
