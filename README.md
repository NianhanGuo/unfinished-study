# 未完成的习作 / Unfinished Study · V7

Unity 6000.0.34f1，Mac 第一人称恐怖绘画小游戏。

## 开始游戏

打开 `Mac-v7/Unfinished Study.app`，按 Return 或点击 FINISH THE HOMEWORK 进入任务纸条。读完后再次按 Return 或点击 PUT THE NOTE AWAY，玩家会折起纸条收好，再拿出画板。

1. WASD 移动，鼠标转头，头灯跟随视线。
2. 找到标有 01 的骨架，把画面中心对准躯干，持续观察约 1.2 秒。圆环填满后获得 5 秒绘画记忆。
3. 按住空格或鼠标左键低头画画。手会跟随笔画，纸上留下真实炭笔线条；右侧显示绘画阶段、百分比和剩余记忆。
4. 松开按键抬头。头灯照到骨架躯干时它会静止，低头后它会重新靠近。画画时仍可移动，但速度变慢。
5. 记忆耗尽时重新观察。画完当前对象后，寻找 02 和 03；已完成的骨架仍会追逐。
6. 完成两具骨架与一组石膏头像、梨和白布静物，最后一笔落下后顶灯亮起。片刻后展示三张完成的习作。

接触骨架会触发手伸向画板、破坏素描与切黑的失败结局。没有尖叫跳脸。
ESC 暂停／继续；结束后按 R 重来。建议戴耳机，从较低音量开始。

## Unity 工程

打开 `UnfinishedStudy`，场景为 `Assets/Study/Studio.unity`。采用内置渲染管线，不依赖 URP 或额外插件。

- `Assets/Study/Scripts`：玩家、绘画、骨架追逐、寻路及自动检查。
- `Assets/Study/ArtV2`：OBJ 模型、真实材质、录音与来源说明。
- `Assets/Study/ArtV4`：连续手部网格、光束贴图和说明。
- `Assets/Study/ArtV3`：三张炭笔画稿及完整生成 prompt（GENERATION.json）。
- `Assets/Study/Resources`：纸张、完成画作、逐笔路径 JSON、着色器和字体。
- `Assets/Study/Editor/StudioBuilder.cs`、`StudioUpgrade.cs`、`StudioRealism.cs`：场景生成器。
- `Tools`：可选的模型／画稿生成源代码。打开或运行游戏不需要 Python。

菜单 Study > Build Studio 会重建生成场景，覆盖该场景中的手工调整。手工修改前请另存场景。骨架敌人采用独立硬质部件与程序驱动姿势。V7 双手在 Blender 中利用关节骨架摆姿后烘焙为连续网格；游戏运行时不需要 Blender。
