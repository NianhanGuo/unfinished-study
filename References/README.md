# Professor modeling reference

Primary image: **Max Planck, Berlin, 11 January 1933**, photographer unknown.

- Source: https://commons.wikimedia.org/wiki/File:Max_Planck_1933.jpg
- Original: https://upload.wikimedia.org/wikipedia/commons/c/c7/Max_Planck_1933.jpg
- Wikimedia Commons identifies the image as public domain under its anonymous-work notice. See the source page for its full jurisdictional explanation and attribution information.
- Local copy: `Max-Planck-1933-reference.jpg`.

Used as a visual reference for receding hair, cranial proportions, deep eye sockets, cheek planes, wire-frame spectacle construction and restrained academic clothing. The game character is fictional: the portrait's moustache and bow tie are not reproduced, and the ceiling anatomy / extensible neck are original game design. The photo is not projected onto the mesh and is not included in game Resources.

Editable original asset: `Blender/Professor/Professor.blend`.
Reproducible modeling script: `Tools/build_professor.py`.
Unity import: `Study > Import Professor Artwork` (or bridge `professorassets`).
